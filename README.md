# Sol's RNG Auto Farm Macro

Rolls for you while you are away and keeps going through the night, with a hotkey that hands control straight back.

## Download

[Download the latest release](../../releases/latest) — portable build, no installer and no account.

## What it does

- Auto-roll on a timer you set, in milliseconds
- Craft mode: repeats a recorded key sequence in batches
- Biome mode: a second sequence on a longer interval
- Record sequences from your own keyboard, no scripting
- Global hotkey to start and stop without leaving the game
- Random jitter so the timing is not machine-perfect
- Run counter showing how many loops have completed
- Small installer, no extra components, free and open source (MIT)

## Requirements

Windows 10 or 11, 64-bit. No admin rights, nothing written to the registry.
